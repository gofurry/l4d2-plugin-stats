# v1.3.4 测试与验收清单

本清单验收 Collector/Dashboard `1.3.4`、Stats schema 6、Dashboard schema 17，以及不改变现有 gameplay/statistical contracts 的原生 L4D2 MOTD 游戏内页面。

## 1. 自动检查

在仓库根目录执行：

```powershell
./scripts/build.ps1
Set-Location dashboard/frontend
pnpm test
pnpm typecheck
pnpm lint
pnpm build
Set-Location ..
go tool sqlc generate
go test ./...
go vet ./...
```

预期：SourcePawn 使用 `1.12.0.7246` 编译成功；前端、Go、迁移、Atlas 和 SSR 测试全部通过；`git diff --check` 无错误。

## 2. 版本与迁移

- `sm_lps_status` 显示 `version=1.3.4`、`schema=6/6`、`state=ready`；
- `l4d2-stats version` 显示 `1.3.4`；
- `l4d2-stats migrate status` 显示 Dashboard schema 17；
- `doctor` 和 `doctor --deep` 不报告新的 error；
- 旧 Dashboard DB 从 16 自动升级到 17，现有服务器、公告、站点设置、成就、徽章和个人可见性保持不变。

## 3. 管理后台

进入“游戏内页面”：

- 启用/关闭状态、默认标题、描述、Banner、Background、完整网站 URL 可以保存并重载；
- Banner、Background、网站拒绝相对 URL、非 HTTP/HTTPS URL、带账号密码的 URL 和超过长度限制的 URL；安全 query string 可以保存；
- 首页三个模块可独立开关；
- 三个生涯亮点指标只能选择 Catalog 中不同的项目；
- Home、Player、Rankings、Content 只能选择界面提供的固定缓存预设；
- `public_origin` 或 A2S server key 缺失时，MOTD 部署帮助显示明确提示；两者齐全时能预览目标页面并复制完整 `motd.txt`。

在“服务器管理”展开一台服务器：

- Title 支持 inherit/override；Description、Banner、Background、Full Website 支持 inherit/override/hidden；Background 的 inherit/override/hidden 分别解析为全站背景、单服背景和无背景；
- Highlights 支持 inherit/override，override 时必须选择三个不同指标；
- 简介、指令、资源分别支持 inherit/override/hidden，只有 override 需要 Markdown；
- 保存全站设置、单服覆盖或文档后，已打开的 `/ingame` 在对应缓存范围内立即看到新内容。

## 4. HTTP 与隐私

直接访问并检查：

```text
/ingame
/ingame?server=<server_key>
/ingame/player/<steamid64>?server=<server_key>
/ingame/rankings?server=<server_key>
/ingame/info/<document>?server=<server_key>
/ingame/announcement/<id>?server=<server_key>
```

- 没有 server 参数且只有一个可识别服务器时自动选择；多个服务器时显示选择页；无效 server key 显示轻量错误页；
- Home、Player、Rankings、Info、Announcement 的所有内部链接保留当前 server key；
- 页面源代码没有 `<script>`、React、module、`fetch`、XHR 或前端 API fan-out；
- JS 传输为 0；单页 HTML 小于 40 KiB，CSS 小于 25 KiB，Achievement PNG Atlas 小于 250 KiB；
- Markdown raw HTML、脚本、iframe、音视频、style、外部图片和危险链接不会执行或加载；
- Markdown 中通过校验的 HTTP/HTTPS 链接使用 Steam 外部浏览器入口，危险 scheme 不生成链接；
- HTML 引用的 CSS/PNG 路径包含非空内容指纹，不再固定为 `v1.3.4`；修改嵌入资源后路径变化，相同内容路径稳定；
- HTML、CSS、PNG 分别返回 `text/html; charset=utf-8`、`text/css; charset=utf-8`、`image/png`，且都不回归 `application/octet-stream`；
- 即使浏览器带有本人 Steam 登录或管理员 Cookie，游戏内个人页仍只显示匿名访客可见 Tab；
- 修改玩家公开可见性后，游戏内 Player Cache 立即失效，不会继续显示旧权限内容。

## 5. 性能与降级

- Home 缓存命中不执行 Stats DB 查询，也不执行或调度 A2S；
- Home 缓存未命中只使用已持久化 A2S 快照；在线真人最多处理 32 人，亮点最多执行 3 个有界查询，不出现逐玩家 N+1；
- Player 只查询公开 Tab 对应的数据；Relationships 只显示 Top 3；
- 可选的亮点、成就、关系、公告或文档查询失败时，其余页面仍返回 200；
- 同一个缓存 Key 并发首次请求被 singleflight 合并；刷新失败时存在旧值可安全降级；
- 公开限流允许 16–32 名玩家短时间打开 MOTD，同时管理员登录/CSRF 限制保持不变。

## 6. Windows Steam + L4D2 必测

这部分不能由普通浏览器自动化替代，必须使用生产环境同版本的 Windows Steam 和 L4D2 客户端：

1. 把后台生成的 HTML 写入游戏服务器 `left4dead2/motd.txt`，`host.txt` 只保留普通文本；
2. 进入对应服务器，按 H 打开原生 MOTD；
3. 确认页面接近吃满 MOTD viewport、左右仅保留 8–12px 安全边距、没有横向溢出，当前服务器名称/地图/人数正确；
4. 分别验证 Background 正常、404 fallback、Banner 正常和 Banner 404；缺图时内容仍完整可用；
5. 检查 168px Home Hero、无 Banner 紧凑 Hero、半透明 Panel、小圆角、轻阴影、自定义纵向 scrollbar；
6. 验证 Online、Offline、Stale、在线玩家和三张生涯亮点卡；
7. 打开 Player，检查 64px 成就徽章、PvE、成就、陪伴和对抗布局，不应依赖负 margin；
8. 打开 Rankings、简介、指令、资源、公告、服务器选择页和错误页，再返回 Home；子页不能重复 Banner，只显示 Compact Server Header；
9. 点击 Markdown HTTP/HTTPS 外链和“完整网站”，都必须拉起本机普通外部浏览器，不能只在 MOTD WebView 内导航；
10. 冷缓存和热缓存各打开一次，确认热缓存 CSS 已使用 Visual v2 指纹地址，而不是旧 `/v1.3.4/ingame.css`；
11. 确认页面只有正常纵向 scrollbar，没有横向 scrollbar。

真实 Steam/L4D2 客户端中的 MOTD 兼容性与外部浏览器 scheme 只有完成本节后才能判定通过。
