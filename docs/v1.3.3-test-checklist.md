# v1.3.3 测试与验收清单

本清单验收 Collector/Dashboard `1.3.3`、Stats schema 6、Dashboard schema 16 与兼容扩充后的 Achievement Contract v1。

## 自动检查

1. 在 `dashboard/frontend` 执行 `pnpm test && pnpm typecheck && pnpm lint && pnpm build`，确认 38 张 source 生成 768×896 Atlas。
2. 在 `dashboard` 执行 `go test ./...` 与 `go vet ./...`。
3. 使用 SourceMod 1.12 执行 Collector 编译和契约校验；本版本只改版本号，不增加采集字段。

## 界面验收

1. 打开玩家中心“成就”，确认分类栏在“战斗”和“支援”之间出现“武器”。
2. 确认武器分类包含投掷专家与 8 个武器专精，生涯分类包含机关大师/药不能停，支援分类包含火力升级。
3. 确认未解锁项显示进度，达到多个 Tier 的历史玩家在 Backfill 或首次打开资料后一次补齐已达 Tier。
4. 确认新徽章可加入最多 3 个展示位，Preview 与玩家页仍复用同一 Badge 样式。

## 数据口径抽查

1. 投掷数 = PvE 三类投掷物 actions + 对抗幸存者三类 thrown 计数。
2. 机关、药物和弹药包均为 PvE + 对抗幸存者生涯累计。
3. 武器击杀只读取 PvE 终身聚合；`OtherFirearm`、投掷物不进入专精，Chainsaw 不进入近战，M60/Scout/AWP 不进入重火力。
4. 运行原始装备明细清理后再次打开玩家资料，确认武器成就进度不下降。

## 不变项

- 无 Stats 或 Dashboard schema 迁移。
- 无 Collector 新字段，`stats_version` 仍为 1。
- 无手动刷新、领取或撤销。
- 原有 63 个 Achievement 的 key、threshold、可见性与 Backfill 语义不变。
