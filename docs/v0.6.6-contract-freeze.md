# v0.6.6 Versus v1 契约冻结

v0.6.6 不新增游戏统计，也不需要再打一场对抗。它把已经通过本地验收的 v0.6.x 数据
模型冻结为未来 Go 读取侧可以直接实现的 Versus v1 契约。

## 冻结内容

- 六张对抗表的精确字段顺序和主键；
- `stats_version=1`；
- 七个固定感染者职业 ID；
- 每个字段的所有者、单位、归属和 Bot 语义；
- 总表与职业表的合计不变量；
- 半场槽位、累计分、平局、异常结束和特殊值语义；
- 缺失总表与缺失职业子行的不同含义；
- Go 读取侧的过滤、聚合和隐私规则；
- 后续变更必须新增迁移的兼容性边界。

## 自动验收

运行：

```powershell
python scripts/validate_versus_contract.py
python scripts/test_sqlite_migration.py
./scripts/build.ps1
./scripts/package.ps1
```

预期：

- 三种数据库的六张 Versus 表严格匹配机器清单；
- 10 条公共数据健康查询在正确快照上全部返回 0；
- 回归测试能检测故意制造的槽位和职业合计错误；
- SourcePawn 编译为零错误、零警告；
- 发布包包含插件、三套迁移、冻结契约、查询示例和健康查询。

## 兼容规则

从本版本起：

1. 不再直接修改 Versus v1 在 `0001_initial.sql` 中的结构；
2. 新结构使用 `0002` 或更高迁移，并同时支持三种数据库；
3. 索引等兼容变化仍需新迁移；
4. 字段单位、含义、所有者或 Bot 语义改变时必须保留旧数据并提高 `stats_version`；
5. Go 侧只读取明确支持的版本，不执行迁移，也不暴露 IP。

## 延期内容

双方真人、换队、Tank 交接、重连、半场重开以及 MySQL/PostgreSQL 实机运行仍在 v0.7.0
验收。跨 Run 稳定队伍、连续推进曲线、第三方计分插件分项和 MVP 不属于 Versus v1。
