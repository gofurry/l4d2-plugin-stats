# L4D2 Player Stats v1.3.3 成就扩充实施文档

本版本以 v1.3.2 为基线，只扩充 Achievement Catalog、Metric Resolver、前端分类和 Badge Artwork。实际仓库已有 Dashboard schema 16，因此保持 schema 16；Stats schema 6、`stats_version=1`、Achievement Contract v1 与其他契约版本不变。

## Catalog

新增 12 个成长系列、42 个底层 Tier：投掷专家、机关大师、药不能停、火力升级、单喷足以、电锯狂魔、枪林弹雨、冲锋陷阵、一发入魂、重火力、爆破专家和冷兵器大师。所有新项目均为 `public` 且计入完成度。

前端分类顺序为：全部、生涯、战斗、武器、支援、Boss、对抗、羁绊、特殊。机关大师与药不能停归入生涯，火力升级归入支援，其余新系列归入武器。

## 指标解析

- 投掷专家：PvE 燃烧瓶/土制炸弹/胆汁罐终身 actions + Versus Survivor 三类投掷次数。
- 机关大师：PvE + Versus Survivor `objective_interactions`，保持采集器既有 allowlist 成功完成语义。
- 药不能停：PvE + Versus Survivor 的止痛药与肾上腺素使用数。
- 火力升级：PvE + Versus Survivor 的燃烧与高爆弹药包部署数。
- 武器专精：只读取 Dashboard 终身 `pve_equipment` 聚合，每个家族累加 Common + Special + Tank + Witch 击杀。

武器映射和所有 threshold 由 [`Achievement Contract v1`](../contracts/achievement-v1.md) 冻结。一次玩家评估仅执行有界的批量查询与一次终身装备聚合读取，不为单个成就发起 SQL。内部 `catalog-v1.3.3` revision marker 会在升级后自动重开一次可恢复 Backfill，避免已评估玩家因数据水位未变而错过新成就。

## Artwork

Manifest 从 26 个 key 扩充为 38 个，Atlas 保持 6 列、128×128 tile，行数由 manifest 自动计算，当前输出为 768×896。新增 12 张为可替换的 256×256 无文字占位 WebP，后续正式美术必须保持相同文件名与 artwork key。

## 非目标

不新增 Collector 字段或数据库迁移，不改 Badge 组件协议，不提供手动刷新、手动判定、领取或撤销功能。历史玩家继续通过现有 Backfill 与访问时按需评估补发。
